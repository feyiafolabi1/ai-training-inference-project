# AI Training and Inference Engineering

A hands-on engineering project focused on understanding, building, profiling, and optimizing modern AI training and inference systems, with an emphasis on AMD GPU architecture and the ROCm ecosystem.

## Project Goals

- Develop a deep understanding of GPU architecture, memory hierarchies, and execution models.
- Learn GPU kernel programming using HIP/C++ and Triton.
- Implement and optimize core AI operations, including GEMM and attention.
- Explore transformer architectures, KV-cache management, quantization, and speculative decoding.
- Understand and optimize LLM inference using frameworks such as vLLM and SGLang.
- Study distributed training, multi-GPU communication, and memory-efficient training techniques.
- Develop practical GPU benchmarking, profiling, and performance optimization skills.
- Apply these concepts in an end-to-end AI inference optimization project on AMD Instinct GPUs.

## Approach

The project combines theoretical foundations with hands-on implementation, benchmarking, and performance analysis.

Each chapter builds toward increasingly complex AI systems engineering challenges, progressing from GPU execution fundamentals to custom kernels, inference optimization, and distributed computing.

## Technologies

Python · C++ · HIP · Triton · ROCm · PyTorch · vLLM · SGLang · RCCL

## Repository Structure

Each chapter has its own directory containing coding exercises, experiments, and a detailed README documenting the concepts explored and lessons learned.

The long-term objective is to build practical expertise in AI systems performance engineering, particularly the interaction between model execution, GPU hardware, memory efficiency, and computational throughput.
